# 《合成大西瓜》互動遊戲網站規格書

## 一、專案基本資訊

- **專案名稱：** 合成大西瓜（Watermelon Game）
- **專案類型：** 休閒益智類網頁遊戲
- **開發方式：** Vibe Coding（透過 AI 協助程式開發）
- **使用技術：** HTML、CSS、JavaScript
- **最終成果：** 單一 `index.html` 檔案
- **支援裝置：** 電腦、手機、平板
- **執行方式：** 使用瀏覽器直接開啟，不需安裝額外軟體

## 二、遊戲設計理念

本次專案希望製作一款簡單、有趣且容易上手的「合成大西瓜」遊戲。玩家透過投放不同大小的水果，讓相同種類的水果碰撞並合成更大的水果，最終目標是合成西瓜並挑戰最高分。

遊戲採用可愛扁平化的視覺風格，搭配柔和的背景色彩與簡單的操作介面，讓玩家能夠專注於遊戲本身。

除了基本的水果合成機制，本次特別重視物理效果，希望水果掉落時具有自然的重力、碰撞、滾動、位移與擠壓效果，增加遊戲的真實感與趣味性。

## 三、遊戲功能需求

### 1. 水果投放系統

- 玩家可以使用滑鼠或手指控制水果的投放位置。
- 點擊滑鼠或放開手指後，水果會從上方自然掉落。
- 每次投放後，系統隨機產生下一顆水果。
- 畫面顯示下一顆水果的預覽。
- 設置短暫的投放間隔，避免玩家連續誤觸。

### 2. 水果合成系統

遊戲設計 11 種水果等級，依照大小排列：

1. 櫻桃
2. 草莓
3. 葡萄
4. 橘子
5. 檸檬
6. 蘋果
7. 梨子
8. 桃子
9. 鳳梨
10. 哈密瓜
11. 西瓜

當兩顆相同等級的水果碰撞時，會合成下一個等級的水果，並增加遊戲分數。

當兩顆最高等級的西瓜碰撞時，會產生消除效果並獲得額外分數，讓玩家可以繼續挑戰更高紀錄。

### 3. 物理碰撞系統

這是本次遊戲最重要的功能之一。

- **重力效果：** 水果投放後會受到重力影響，自然向下掉落。
- **碰撞效果：** 水果撞到其他水果或容器邊界時，會產生碰撞反應。
- **位移效果：** 水果碰撞時會推動其他水果，使堆疊位置產生變化。
- **擠壓效果：** 當多顆水果堆積在一起時，會產生推擠與輕微的視覺壓縮效果。
- **滾動效果：** 水果落在其他水果上方時，會依照碰撞角度自然滾動。
- **摩擦與彈跳：** 水果具有適當的摩擦力與彈性，避免不自然的滑動或穿透。

物理系統使用 JavaScript 實作，讓遊戲不需要依賴外部程式庫也能執行。

### 4. 分數與紀錄系統

- 畫面上方即時顯示目前分數。
- 合成不同等級水果時，依照等級獲得不同分數。
- 顯示玩家歷史最高分。
- 使用瀏覽器 localStorage 儲存最高分。
- 重新整理網頁後，最高分仍可保留。

### 5. 遊戲控制功能

**暫停與繼續：**

玩家可以隨時暫停遊戲，暫停時水果停止移動，遊戲計時及物理運算也會暫停。按下繼續後恢復遊戲。

**重新開始：**

玩家可以點擊重新開始按鈕，清除目前所有水果與分數，重新進行遊戲，但保留最高分紀錄。

**遊戲結束：**

遊戲容器上方設有警戒線，當水果堆積超過警戒線並持續約三秒，遊戲結束。畫面顯示最終分數、最高分與重新挑戰按鈕。

## 四、視覺與介面設計

### 1. 整體風格

採用可愛、簡約的扁平化插畫風格。

- 背景使用米白色、奶油色等柔和色調。
- 水果使用鮮明但不刺眼的顏色。
- 水果具有簡單可愛的表情。
- 按鈕採用圓角設計。
- 整體畫面保持乾淨、容易辨識。

### 2. 遊戲畫面配置

**上方資訊區：**

- 遊戲名稱「合成大西瓜」
- 目前分數
- 歷史最高分
- 下一顆水果預覽

**中央遊戲區：**

- 水果投放位置
- 水果掉落與碰撞區域
- 水果合成動畫
- 遊戲結束警戒線

**下方控制區：**

- 暫停／繼續按鈕
- 重新開始按鈕
- 簡單操作說明

### 3. 動畫效果

- 水果掉落與碰撞動畫。
- 相同水果合成時的放大與彈跳效果。
- 合成成功時的粒子特效。
- 得分時短暫顯示增加的分數。
- 遊戲結束時顯示結果畫面。

## 五、操作方式與裝置相容性

### 電腦版

玩家使用滑鼠左右移動，控制水果的投放位置，點擊滑鼠即可投放。

### 手機與平板版

玩家使用手指拖曳調整水果位置，放開手指即可投放。

網頁採用響應式設計，遊戲畫面能夠依照不同螢幕尺寸調整，確保在電腦、手機和平板上都能正常操作。

## 六、技術實作規格

本專案使用以下技術：

**HTML：** 建立網頁基本結構、遊戲畫面與操作按鈕。

**CSS：** 設計遊戲介面、水果配色、背景、按鈕及響應式排版。

**JavaScript：** 處理遊戲邏輯，包括水果投放、重力運算、碰撞偵測、水果合成、分數計算、遊戲狀態與操作事件。

**HTML Canvas：** 繪製水果、動畫、遊戲容器及即時物理畫面。

**localStorage：** 儲存玩家最高分紀錄。

所有 CSS 與 JavaScript 程式碼都直接寫在 HTML 檔案內，最終只需要一份 `index.html`，不需要額外的 CSS、JavaScript 或圖片檔案。

## 七、遊戲流程

1. 玩家開啟網頁，進入遊戲畫面。
2. 系統顯示目前分數、最高分及下一顆水果。
3. 玩家移動滑鼠或手指，選擇水果投放位置。
4. 玩家投放水果，水果受到重力影響自然掉落。
5. 水果與其他水果碰撞，產生滾動、位移及擠壓效果。
6. 相同水果碰撞後合成更大的水果，並增加分數。
7. 玩家持續投放水果，挑戰合成西瓜。
8. 當水果持續超過警戒線時，遊戲結束。
9. 系統顯示最終分數，玩家可以重新開始挑戰。
